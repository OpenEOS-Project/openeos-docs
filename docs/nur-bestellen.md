# Nur Bestellen (ohne Kasse)

„Nur Bestellen“ heißt jetzt **„Nur Bons“** und ist eine von drei Betriebsarten deiner Organisation. Du musst sie nicht mehr beim Support beantragen: Als Admin wählst du sie selbst unter **Einstellungen → Organisation → Betriebsart**.
