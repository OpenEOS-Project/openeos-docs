# Dashboard

Das **Dashboard** ist deine Startseite nach der Anmeldung. Es gibt dir einen schnellen Überblick über die aktuelle Geschäftstätigkeit deiner Organisation.

![Dashboard](/img/screens/de/dashboard.png)

## Kennzahlen

In den Kacheln am oberen Rand siehst du auf einen Blick:

| Kachel | Bedeutung |
| --- | --- |
| **Bestellungen heute** | Anzahl der heute erfassten Bestellungen (im Vergleich zu gestern) |
| **Umsatz heute** | Heutiger Umsatz (im Vergleich zu gestern) |
| **Aktive Events** | Anzahl der aktuell laufenden Veranstaltungen |
| **Aktive Benutzer** | Aktuell online angemeldete Benutzer |

## Letzte Aktivitäten

Darunter listet der Bereich **Letzte Aktivitäten** deine neuesten Bestellungen und Transaktionen auf. Solange noch keine Bestellungen erfasst wurden, erscheint hier ein Hinweis – starte eine Veranstaltung, um Bestellungen anzunehmen.

## Dashboard anpassen

Über die Schaltfläche **Anpassen** oben rechts kannst du die angezeigten Inhalte des Dashboards an deine Bedürfnisse anpassen.

![Dashboard anpassen](/img/screens/de/dashboard-customize.png)

## Aktive Veranstaltung

Links in der Seitenleiste siehst du die aktuell **aktive Veranstaltung**. Viele Bereiche – etwa Produkte, Standorte und Inventur – beziehen sich immer auf das gerade aktive Event. Steht dort „Kein aktives Event“, aktiviere zunächst eine Veranstaltung (siehe [Veranstaltungen](./veranstaltungen.md)).
